# DVWA Laboratory Setup

## Overview

This document describes the laboratory environment configured for my academic web application penetration testing project.

## Laboratory Requirements

- Kali Linux
- Apache2
- MariaDB
- PHP
- Git
- Web browser
- Damn Vulnerable Web Application (DVWA)

## Environment Configuration

### 1. System Preparation

Updated the Kali Linux environment and installed the required software packages.

### 2. Web Server Configuration

Installed and configured Apache2 to host the DVWA application locally.

### 3. Database Configuration

Installed MariaDB and created a dedicated database and database user for DVWA.

### 4. DVWA Installation

Downloaded DVWA from its official GitHub repository and placed it inside the Apache web root directory.

### 5. Application Configuration

Configured the database connection and initialized the application database.

### 6. Security Configuration

Accessed DVWA through localhost and configured the security level to Low for controlled vulnerability testing.

## Testing Scope

- Stored Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
